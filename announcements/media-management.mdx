## What is changing

Studio now shows all media Occtoo handles, with more tools to work with it. Until now only files uploaded manually appeared in the Media area. With Media Management, files imported from other systems appear too and have the same capabilities as uploaded files.

A media library is a source like any other. It sits next to your product data, you enrich it the same way, and it flows to the same destinations.

## Why we are doing it

Media is product data, and teams spend a lot of time finding, tagging and delivering files.

- **All your media in one view** — every file Occtoo handles, whether uploaded, integrated or sourced elsewhere, not just uploads.
- **One place for everything about a product** — files and data side by side, no switching between tools.
- **Structure that grows with the catalogue** — nested folders, each with its own enrichment layout if needed.
- **Less time on mechanics** — search, filter and act on many files at once.
- **Confidence that files arrived** — progress and clear results, nothing to check back on.
- **Media your systems can feed** — integrations upload files the same way they deliver data.

## What changes when working with media

- **Media sources** — media libraries are listed and managed alongside product data.
- **Nested folders** — folders inside folders. Rename, move and delete them from the tree, which shows file counts.
- **Upload from anywhere** — drag and drop in Studio, or upload from other systems through the SDK and API.
- **Find and act in bulk** — search, filter and sort within a folder. Move, edit or delete a selection, or download it as a zip, with progress shown.
- **Clear file status** — the file name and progress show while uploading, and failed uploads are marked as failed.
- **Enrichment you design** — choose, group and order the properties to fill in, and adjust them per folder. List and multi-language fields are supported.

![The Property layout dialog with grouped properties and system properties](/images/announcements/media-management/property-layout.png)

- **A better file view** — see a file's location, ID, upload and change dates, and direct link, with a zoomable preview. **Replace** swaps the file in place and keeps its ID and enrichment.

![The file view with the zoomable preview, properties and the System section](/images/announcements/media-management/file-details.png)
