## Partner overview

**Occtoo Start 1–2–3** is a partner-led framework for implementing Occtoo as a **Product Orchestration Engine for data and media**.

Rather than a strict sequence, the model consists of **three parallel layers** that reinforce each other:

1. Data Activation
2. Hyper-intelligent Products
3. Process & New Roles

The framework helps partners guide customers from technical enablement to measurable business impact—without turning the implementation into a purely IT-driven project.
