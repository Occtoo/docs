---
title: "Occtoo blocks"
---

Occtoo turns Enterprise data into Experience data, making it easier to build new and innovative applications. In other words, you can extract multi-domain data from sources within any organization, onboard this data to Occtoo, and create dynamic real-time APIs to power stunning user experiences at lightning speed.

To achieve all this, we have defined a set of steps and processes - Occtoo blocks. The blocks are the DNA of what Occtoo is and how it works.
