---
title: "Edit a segment"
---

You can edit your segment anytime using the 'Edit' button in the right corner

![An image from the static](/images/edit-segment-a8cc8c0349888ada71913fa215ca4a94.png)

To change the query criteria, simply use the 'Clear' button and proceed with the new selection

![An image from the static](/images/clear-query-f372bea6f39688979b16d2cff5d329eb.png)

Now you can easily filter the data that you would like to include in the endpoint. You will see the result of your filtering in the middle column.
Once you are happy with the filtering, click 'Apply' to add it to the segment.
When changing the query criteria, please allow a few minutes after saving for the new settings to be processed.

![An image from the static](/images/segment-filters-30aa04660dd030fdffd80af902430860.png)
