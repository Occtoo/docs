---
title: "Delete a segment type"
---

Click on the menu to the right and select "Manage Segment Type"

![An image from the static](/images/AddSegmentType_1-8072d7f9d4c804bef7c227871d8fce20.png)

In the popup click on the "Basket" icon right next to the name of the segment type

<Info>
You are only able to delete a Segment type that is not used in a Segment
</Info>

![An image from the static](/images/DeleteSegmentType_1-688881d1bd783c696652b8ef38bbdb5b.png)
