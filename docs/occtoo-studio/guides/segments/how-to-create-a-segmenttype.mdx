---
title: "Create a segment type"
---

To be able to create your segment, first you need to create a segment type.

<Info>
A segment type is a definition build on a specific card
</Info>

Click on the menu to the right and select "Manage Segment Type"

![An image from the static](/images/AddSegmentType_1-8072d7f9d4c804bef7c227871d8fce20.png)

Click on "Create Segment type" at the bottom of the pop-up

![An image from the static](/images/AddSegmentType_2-26decf1cc147ac3a046544e66fa9e0dc.png)

Fill in the information

- Name - Name of your segment type
- Identifier - This field is prefilled but can be updated
- Description
- Card - Select what card you build your segment type of
- Color - Select the color that should respresent the segment type
- Placeholder icon - Select the icon that will respresent the segment type

![An image from the static](/images/AddSegmentType_3-445d7604a1145d8519c1bd831d2c8bf7.png)

Click on "Next"

Select what field you would like to use as a filter based on your segment type.

<Info>
You will be able to filter on more then the selected attribute but they will be pre-selected in the segment filter view
</Info>

![An image from the static](/images/AddSegmentType_4-aaf826d4d1f21317e7362d6ad59acbdb.png)
