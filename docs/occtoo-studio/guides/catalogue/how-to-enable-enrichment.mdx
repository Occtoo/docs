---
title: "Enable enrichment"
---

From the selection in the catalog, it is possible to select specific entries to manage on a more detailed level. By enabling enrichment of certain properties, the user is allowed to manually edit the values based on the selected data types.

![An image from the static](/images/catalogue-enable-enrichment-1-cefd560db9d187ff1a01627833678c1e.png)

To be able to enrich data and adjust a specific fields value, the property 'Allow enrichment' must be set to **Yes**. If set to **No** the property will be greyed out and readonly. Also the 'Show on interface' needs to be set to **Yes**, otherwise the property will not be displayed in the user interface.

- **Show on interface** = Yes
- **Allow enrichment** = Yes
