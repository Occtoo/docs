title: "Switch between environment"
---

If you are assigned to several environment you are able to switch between the environments.

The selected environment is visible in the right hand corner

![An image from the static](/images/SwitchEnviroment-41a385cad418a862e61d242f045783e9.png)

If you have several enviroments

<Info>
Click on the arrow and select the new enviroment
</Info>
