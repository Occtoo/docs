---
title: "Select a property in a endpoint"
---

In the endpoint you have the posibility to descied what property to included in the endpoint

- Click on you endpoint is it opens in detail view
- Click on Advanced setting
- Click on the name of your card
- Check/Uncheck the properties that should be included/Excluded
- Save the setting

![An image from the static](/images/destination-select-property-003be6c4199bf75af3f47408430401e3.png)

<Note>
If your destination is Published you need to create a new version of the destination to be able to change the properties
</Note>
