## Introduction

This is a template project for creating provider to onboard data from a [XML file](https://www.w3schools.com/xml/xml_whatis.asp). Available via [Github](https://github.com/Occtoo/Occtoo.Provider.XML).

## How it works

The program reads the file books.xml and converts each book element into a [Dynamic Entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs). They are then imported into Occtoo using the [OnboardingServiceClient](https://github.com/Occtoo/Occtoo.Onboarding.Sdk)

Check our documentation on [how to set up a Provider in Occtoo Studio](/docs/get-started/provide-data#1a-clientsecret) to get your provider details.

## Download and Installation

Fetch the latest code at our [Github repository](https://github.com/Occtoo/Occtoo.Provider.XML). Build and deploy to your azure instance
