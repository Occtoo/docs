## Introduction

This is a template project for creating provider to onboard data from a [CSV file](https://www.techopedia.com/definition/24364/comma-separated-values-file-csv). Available via [Github](https://github.com/Occtoo/Occtoo.Provider.CSV).

## How it works

The program reads the file Product\_Data\_Sample.csv and converts each row into a [Dynamic Entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs). They are then imported into Occtoo using the [OnboardingServiceClient](https://github.com/Occtoo/Occtoo.Onboarding.Sdk)

Check our documentation on [how to set up a Provider in Occtoo Studio](/docs/get-started/provide-data#1a-clientsecret) to get your provider details.

## Download and Installation

Fetch the latest code at our [Github repository](https://github.com/Occtoo/Occtoo.Provider.CSV). Build and deploy to your azure instance
