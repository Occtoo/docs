title: "Providers"
---

*Provider* is what we call components that push data to Occtoo. Basically, they are integration components that serves as bridges linking systems, applications or services with the Occtoo platform. Its primary purpose is to facilitate data exchange by transforming and mapping data from a source system's format to a format that can be understood and processed by Occtoo.

Dependent on how the data is to be activated and used, a common use case is that the provider splits and restructures the recived payloads to several data sources.

## Ready made integration

On occasion we collaborate with other software vendors and create standard connectors between Occtoo and other systems. These are contionusly monitored and updated to stay up to date with changes to each respective system. Information about these you'll find below.

### Akeneo

Using the [Occtoo App](/docs/Integration/Ingest/Providers/akeneo), from the Akeneo marketplace, users can easily and seamlessly connect their [Akeneo PIM](https://www.akeneo.com) with Occtoo to make product data instantly available to be used by their digital team.

### Bluestone PIM

Our pre-built integration for [Bluestone PIM](/docs/Integration/Ingest/Providers/bluestone), allows to export data, categories, and media from [Bluestone PIM](https://www.bluestonepim.com/).

### inRiver

Using the [Generic inRiver Provider](/docs/Integration/Ingest/Providers/inriver) with Extensions ready to deploy, partners can easily and send data from inRiver to Occtoo.

## Boilerplates

Below is a set of boilerplate projects, all available through the [Occtoo Github](https://github.com/orgs/Occtoo/). Boilerplates are a set of pre-written and reusable templates that provide a foundation or starting point for developing a integration component to push data into Occtoo. The boilerplates are provided *"as is"* under the [MIT license](https://opensource.org/license/mit/).

<Tip>
Are you interested in sharing a boilerplate with the community? Do not hesitate to reach out to us at [developer@occtoo.com](mailto:developer@occtoo.com) so that we can discuss how to go about it.

Sharing is caring ❤️
</Tip>
