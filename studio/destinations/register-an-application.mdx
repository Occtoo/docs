---
title: "Register an application"
---

Before you can query on a protected destination - you need to register an application (i.e. user).
You will receieve a **ClientId** and a **SecretKey** when creating an application - this will be used to generate a token which is then used to access the destination.

<Steps>
  <Step title="Open the destination">

    Open your destination in the detail view.

  </Step>
  <Step title="Open the Application tab">

    Click on the tab **Application**.

  </Step>
  <Step title="Add the application">

    Click on **+ Add application**.

    ![An image from the static](/images/destination-application-1-9f62e696d58ddb47c69d54e91ef1072a.png)

    ![An image from the static](/images/destination-application-2-e902db7bf8f2681d6e69bdbc0afc50b1.png)

  </Step>
</Steps>

<Info>
You are only able to see the clinet secret when creating the application
</Info>

![An image from the static](/images/destination-application-3-e2a548148a44c5b85ba13eaf00b975b9.png)

![An image from the static](/images/destination-application-4-4ba97a7966b23bc3a8809076fc9f19b5.png)

<Info>
To be able to use the destination external following is needed

- Destination ID - You find this in the tab "Settings"
- Client ID - You find that under your created application
- Client secret - You find that when the Application is created
</Info>

![An image from the static](/images/destination-application-5-8c232a6bf8fba78d8f030892e5c54089.png)

<Info>
If you are using a Dynamic or a Static Destination you are only allow to create one application
</Info>
