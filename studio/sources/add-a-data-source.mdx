---
title: "Add a source"
---

<Steps>
  <Step title="Press the Add data source button">

    in the upper right corner you will have a blue “Add data source”-button, press it and you’ll be met with a new pop-up.

  </Step>
  <Step title="Fill in the details">

    From here – you have to add the following data:

    - **Name** - Name of the data source.
    - **Identifier** - Unique identifier of the data source.
    - **Description** - A short description of what the data source is/will be used for.
    - **Shares ID with** - Select if your source is sharing the same Idetifier as another source.

    <Tip>
    Example: Shares ID with - If you would like to build a card that is using data from several data sources use this property to defined what sources that is sharing the same ID
    </Tip>

    ![An image from the static](/images/data-sources-350a6251f17b6df11992e4c2ce5be8c6.png)

  </Step>
  <Step title="Save the data source">

    Fill in the required information and press “Add data source” – your data-source will now appear under “Sources”.

  </Step>
</Steps>

<Info>
A data provider is needs when adding data using a provider to populate the source. If the CSV import feature is used there is no need to add a data provider
</Info>

<Tip>
You can use the import data-function to import a CSV file
</Tip>
