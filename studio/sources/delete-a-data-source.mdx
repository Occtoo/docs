---
title: "Delete a data source"
---

<Steps>
  <Step title="Select the source">

    Select the Source that you would like to delete

    <Info>
    You are only able to delete a data source where no data is entered
    </Info>

  </Step>
  <Step title="Click the Delete icon">

    Click on the Delete icon in the right hand corner

    ![An image from the static](/images/delete-source1-49b1ed385051cd431835a4ac4657dea5.png)

  </Step>
  <Step title="Confirm the deletion">

    Confirm the Delete with the popup

    ![An image from the static](/images/delete-source2-738037debac17571061a0ab77d0e6c00.png)

  </Step>
</Steps>
