---
title: "Remove a data provider"
---

<Steps>
  <Step title="Open Data providers">

    Select the tab Data providers.

  </Step>
  <Step title="Open the provider menu">

    Select the menu at the right on the specific data provider that you would like to remove.

    ![An image from the static](/images/remove-data-provider1-cb92474e333941b77464746ed9041fbd.png)

  </Step>
  <Step title="Confirm the removal">

    Confirm that you would like to remove the data provider

    ![An image from the static](/images/remove-data-provider2-dbc7c6e1ede37dcf861cbb6e5f0587b3.png)

  </Step>
</Steps>
