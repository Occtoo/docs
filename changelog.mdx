<Update label="August 2026" description="Docs" tags={["Documentation"]}>
## New documentation site

The Occtoo documentation has moved to a new platform with a modernized structure:

- **API Reference** — interactive reference for the Ingest API and Events API, generated from our OpenAPI specifications, with a built-in playground and code samples.
- **Integrations** — ingest providers and consumption formatters now live in their own section.
- **Cleaner navigation** — task-based guide names, streamlined URLs, and step-by-step guides using structured steps. All previous URLs redirect to their new locations.
</Update>

<Update label="June 2026" description="Platform" tags={["MCP", "AI"]}>
## Occtoo MCP server

Connect AI assistants to your Occtoo tenant with the [Occtoo MCP server](/get-started/occtoo-mcp). Query sources, inspect schemas, and work with your data directly from MCP-enabled tools.
</Update>

<Update label="June 2026" description="Events" tags={["API"]}>
## Events API

Tenant-scoped events delivered as CloudEvents: pull events with cursors or subscribe to a live Server-Sent Events stream. See the [Events API reference](/api-reference/events/overview).
</Update>
