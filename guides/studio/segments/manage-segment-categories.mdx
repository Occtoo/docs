---
title: "Manage segment categories"
description: "Rename or delete the categories that group your segments."
---

Open the menu in the upper right corner of the **Segments** page and select **Manage segment categories**.

![Manage segment categories in the segments page menu](/images/guides/studio/segments/manage-segment-categories-menu-focus.png)

The dialog lists every category in the tenant, each with a pencil icon to rename it and a bin icon to delete it.

![Manage segment categories dialog](/images/guides/studio/segments/manage-segment-categories-dialog-focus.png)

<Info>
Renaming and deleting require the edit and delete permissions for segment categories. Without them, the icons are disabled.
</Info>

## Rename a category

<Steps>
  <Step title="Start editing">

    Press the pencil icon next to the category name.

    ![Category name in edit mode](/images/guides/studio/segments/rename-segment-category-focus.png)

  </Step>
  <Step title="Save the new name">

    Enter the new name and press the check icon. Press the cross icon to discard the change.

  </Step>
</Steps>

<Info>
Only the name can be changed. The identifier stays the same, so segments already using the category keep working.
</Info>

## Delete a category

Press the bin icon next to the category name. The category is removed immediately.

<Warning>
A category that is used by a segment cannot be deleted. The bin icon is disabled and the tooltip reads "Cannot delete Segment Category that is in use". Move or archive the segments first.
</Warning>

Press **Ok** to close the dialog.

To add a category, see [Create a segment category](/guides/studio/segments/create-a-segment-category).
