---
title: "Create a segment category"
description: "Categories group segments that are built on the same card."
---

Every segment belongs to a category. A category is a label that groups similar card-based segments, so they are easier to organise and find.

You create a category from the segment flow, in the step where you fill in the segment details.

<Steps>
  <Step title="Open the category list">

    Press **New segment** on the **Segments** page, name the segment and pick the card it is based on. Then open **Select a category**.

    The list only shows categories that fit the selected card. Studio preselects the category that matches the card, when there is one.

    ![Category list in the New segment step](/images/guides/studio/segments/new-segment-category-select.png)

  </Step>
  <Step title="Add the category">

    Press **New category**, enter a name and press **Save**.

    ![New segment category dialog](/images/guides/studio/segments/new-segment-category-dialog-focus.png)

    <Info>
    The name has to be unique. The identifier is derived from it.
    </Info>

  </Step>
  <Step title="Finish the segment">

    The new category is selected for the segment. It is created together with the segment when you press **Save segment** at the end of the flow, and is then available for other segments on the same card.

  </Step>
</Steps>

## Where categories are shown

- In the segments list, above the segment name.
- On the segment page, in the **Segment details** widget.
- In the **Category** filter on the **Segments** page, so you can list all segments in a category.

To rename or remove a category, see [Manage existing segment categories](/guides/studio/segments/manage-segment-categories).
