---
title: "Generate documentation for a destination"
---

You can generate documentation for a destination in JSON format - to do this, follow the steps below:

<Steps>
  <Step title="Open the destination">

    Click on your destination - from there you can see multiple tabs - Overview, Endpoints, Regions, Languages, Analytics, Settings and Documentation

  </Step>
  <Step title="Open the Documentation tab">

    Click on the tab named **Documentation**

  </Step>
  <Step title="Click Download">

    Click on **Download**

  </Step>
  <Step title="Choose a download format">

    From there on, choose either:

    - **Download JSON**
    - **Download JSON & Examples**(depending on what kind of documentation you are looking for)
    - This will generate a data-model output in .json format

    ![An image from the static](/images/guides/studio/destinations/destination-documentation-1-714096286a809944398969ea8d5910a3.png)

  </Step>
</Steps>

You can also compare the differences in the data-model across several versions of the destination, to do this press on the **Compare**-button.

![An image from the static](/images/guides/studio/destinations/compare-documentation-159549b7e4747c6528cb4e4cb4fcdd96.png)

<Info>
You will now be able to see what has changed in a side-by-side view from the previous version number published.
</Info>

![An image from the static](/images/guides/studio/destinations/compare-documentation-1-ba6f4691de9deca51e1c1a69e853a47e.png)

The documentation-tab can be helpful and can also be used to see what queryable parameters we have on the destination.

![An image from the static](/images/guides/studio/destinations/compare-documentation-2-42aad8995aa24e6c47258dec812a5c09.png)

<Tip>
In the left side of the pane - we have the **Overview** - under this we can see what endpoints we have available and which ones we can query on.
If you press on one of the endpoints - you can also see what specific parameters we can query on in our API-request.
</Tip>

![An image from the static](/images/guides/studio/destinations/compare-documentation-3-f034e2b2018cfec1c1bf2c8b053d3962.png)

In the image above you can see all of our query parameters - we can add these in our request (for example, &language in the request) when making specific calls towards the API.

<Info>
if you have a localized string for example - and you want to make a request towards a specific language - you can add "&language=no" in your request to receive all the localized fields in the Norwegian language.
</Info>
