### Publish destination without setting up a new version

Changes to the destination is only accepted as long as they don't alter the existing structural integrity. This guarantees not breaking the already setup usage of the API. The possible changes that can be made is listed down below and can never beak the existing contract.

- Adding new properties
- Adding new segments
- Adding relations
- Enabling facets on properties

Newly added properties will be marked in orange color and a "pending changes" symbol will appear indicating that there are unpublished changes.
