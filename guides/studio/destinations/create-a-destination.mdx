---
title: "Create a destination"
---

<Steps>
  <Step title="Add a destination">

    To create a destination, click on the Button **+Add Destination** in the upper right corner.

    ![An image from the static](/images/guides/studio/destinations/destination-add-destination-1-f436b22830fdebd9275242f400ad4c78.png)

  </Step>
  <Step title="Select the destination type">

    Select the destination type you want to create:

    - **Dynamic**
    - **Multi Consumer**
    - **Static**
    - **Enterprise**

    ![An image from the static](/images/guides/studio/destinations/destination-add-destination-0-20b05f12aeda04f91a5ddf4956a1f39f.png)

    <Info>
    Read more about the different [destination types](/concepts/destination-types)
    </Info>

  </Step>
  <Step title="Add the destination information">

    Add following information

    - **Display name** - Use a name that best matches the intent of your destination.
    - **Safe name** - Will be added automatically but you will have the possibility to change this afterwards.
    - **Description** - Describe the purpose of the destination
    - **Source language code** - Language code that has been on boarded to the destination.
    - **Destination language code** - The code that you would like to share in the endpoint
    - **Default language** - Preferred language(s) on the endpoint - you can add several. Cannot be updated or edited after the destination has been published.
    - **Regions** - In which regions should your destination be included?
    - **Default region** - Which region should be used as the default region?

    ![An image from the static](/images/guides/studio/destinations/destination-add-destination-2-7dc874a3ce95483db1ac1f0d76e80006.png)

    <Info>
    You are only able to select Regions if the client has requested several regions in their contract.
    </Info>

  </Step>
</Steps>
