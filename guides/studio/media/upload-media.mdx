---
title: "Upload media"
---

You can use the Media feature in Occtoo Studio to create folders and upload media objects in different formats. Follow the steps below to learn more details about this.

<Steps>
  <Step title="Create a source">

    To begin with we are going to need somewhere to store our uploaded images. This is done by creating a data source in the Occtoo Studio. A tutorial about this can be found in the section "Add a source"

  </Step>
  <Step title="Create a card">

    In order to choose what kind metadata that is going to be applied a card needs to be created. It is possible to determine the datatype for different properties and also create a pre set selection of list values that can be chosen by the user when enriching specific fields. More info about this can be found in the "Create a card" section.

    <Info>
    You can create preset options and set the order of properties if you edit them and choose "Display settings".
    ![An image from the static](/images/edit-property-544c3447adb428dc01c92390810759b6.png)
    </Info>

  </Step>
  <Step title="Create an upload folder">

    Once the card is completed we are ready to move on to the next step which is creating folders, this is a great way of structuring media. One example which is common is dividing media for different seasons in separate folders, but the structure can be setup however it suits the user. Once you create a folder it has to be connected to a card, in this case we can use the one that was created under the first step of this tutorial.
    ![An image from the static](/images/create-folder-3a2328cbaa52d20d30b38832b205727d.png)

  </Step>
  <Step title="Upload media">

    At this point we are ready to upload our desired media objects. This can be done by entering the folder and simply dragging and dropping. Once the Media has been uploaded you can simply click the object of interest which will open a new window allowing you to enrich the media according to the card setup that was done in step 2 of this guide. You can update media one by one or in batches.
    ![An image from the static](/images/enrich-media-16823d315b14250312f98d563438da2c.png)

  </Step>
  <Step title="Batch edit or delete medias">

    It is possible to update several media objects at once using the batch update.
    This can be done by marking the different medias you're interested in and then press "Edit properties".
    You also have the possibility to delete a media when an object is marked this way.

    ![An image from the static](/images/edit-delete-media-1e0ad199629151a08750f6e7bab5c4f8.png)

  </Step>
</Steps>

Once you are satisfied with your enrichment simply press the save button.
