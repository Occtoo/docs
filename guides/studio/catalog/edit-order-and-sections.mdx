---
title: "Edit order and sections"
---

It is possible to change the order of the attributes and create sections with a collection of attributes, that will be presented in the catalog view. This is meant to increase the visibility and overview while working with the data.

![An image from the static](/images/catalogue-edit-order-1-af250020a4c022acb73d158b7f0ba1ed.png)

Above example has a general tab with all the data included. With a section added the data can be divided into a hierarchy like below.

![An image from the static](/images/catalogue-edit-order-2-edc13b45da46a9cde53e02d8f0b8e072.png)

**Set order of attributes and modify sections**

To set the order of attributes and modify sections, find the ‘Edit order and sections’ button on the relevant card and click the button to open the sorting view.

![An image from the static](/images/catalogue-edit-order-3-e72ada303a91f1ac92a463bc4f54c182.png)

On the right-hand side, each attribute is draggable and can be placed in the desired order of the catalog section. There is also the possibility of adding new sections to group the data.

![An image from the static](/images/catalogue-edit-order-4-12212187a9f483b0449f4e5f8f57a1f4.png)

<Tip>
It is possible to add a property directly to a section when creating the property.
</Tip>
