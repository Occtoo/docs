title: "Managed tags"
---

Managed Tags are reusable, centrally maintained lists of predefined values that can be referenced across multiple data models and experiences within Occtoo. They serve as a consistent way to define and manage shared attributes — such as product categories, regions, customer types, brands, or languages — ensuring data integrity and alignment across all connected systems and channels.

Managed Tags provide a controlled vocabulary for data used throughout your environment. Instead of manually entering or recreating values, Managed Tags allow you to reference a single, authoritative list. This approach guarantees that all teams and experiences use the same terminology, reducing duplication, inconsistency, and maintenance overhead.

## How to create tags

Each tag list can contain multiple items, each with a unique key (ID) and readable label. The display values for the tags can be localized as well as ordinary strings.

## Enable tag on property

To assign a managed tags list to a property, select Edit on the property and choose the list from the available tag lists.
