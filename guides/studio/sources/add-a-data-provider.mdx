---
title: "Add a data provider"
description: "Register an integration that may write to sources, and store its secret."
---

A data provider is the identity an integration uses to write into sources. Before an integration can onboard anything, it needs a provider with access to the sources it will write to.

<Steps>
  <Step title="Open the Data providers tab">

    Open **Sources** in the left navigation and switch to the **Data providers** tab.

    ![The Data providers tab](/images/guides/studio/sources/providers-list.png)

    Each provider shows its name, its provider ID with a copy button, the identifiers of its allowed sources, and when it was last modified.

    <Info>
    The tab is only reachable with the data provider edit permission. Without it, opening it lands you on the access denied page.
    </Info>

  </Step>
  <Step title="Press New data provider">

    ![The Create Data Provider dialog](/images/guides/studio/sources/create-provider-dialog.png)

    - **Name** — required, 2 to 50 characters.
    - **Allowed Sources** — the sources this provider may write to. Pick as many as needed.

  </Step>
  <Step title="Press Create">

    The dialog stays open and shows the generated secret, above the note "Copy and store the secret below before you close this dialog." and "You won't be able to see it again."

    Copy the secret with the copy button.

  </Step>
  <Step title="Press I have copied the secret. Close the dialog.">

    <Warning>
    The secret is shown once and never again. Try to close before copying it and Occtoo warns "You have not copied the secret yet. It cannot be retrieved later." — closing a second time dismisses the dialog anyway, and the secret is lost. If that happens you have to [reset the secret](/guides/studio/sources/reset-a-client-secret).
    </Warning>

  </Step>
</Steps>

## Allowed sources

**Allowed Sources** is the whole of a provider's authorisation: it can write to those sources and nothing else. That lets you scope integrations — several providers writing to one source, or one provider restricted to a single source.

<Info>
A source's own page lists the providers that may write to it, in the **Providers** chip row — see [Track usage of source data](/guides/studio/sources/track-usage).
</Info>
