---
title: "View and edit an entry"
description: "Open an entry to see every property value, change what is editable, and read its changelog."
---

Clicking a row in the **Entries** widget opens the entry panel on the right.

![The entry panel](/images/guides/studio/sources/entry-sheet.png)

## What the panel holds

- The **entry ID** in the header, with a copy button.
- **Current data** — every property on the entry, grouped into the source's display sections, with a **Filter properties** box above.
- **Changelog** — the change history, most recent first.
- **Delete entry** and **Save** in the footer.

<Info>
Unlike the entries table, the panel shows *all* properties, including those with **Show on interface** set to **No**.
</Info>

## Filter properties

**Filter properties** matches on both the property ID and the display name, and hides sections left with nothing in them.

## Editing values

Whether a value can be edited comes from the property, not the entry: only properties whose **Editable** setting is **Yes** get an input. Everything else is displayed as read-only text. In the panel above, every property is read-only because this source defines them all as non-editable.

<Info>
To make a property editable, set **Editable** to **Yes** on it — see [Add or edit a property](/guides/studio/sources/add-and-edit-a-property). System properties are never editable.
</Info>

Editable properties render an input matched to their data type:

| Data type | Control |
| --- | --- |
| Text, Localized text | Text box |
| Integer, Decimal | Number box |
| Boolean | **True** / **False** radio buttons |
| Timestamp | Date and time picker, with a clear button |
| List, Localized list | Multi-select of the current values, with **Add new value** |

A localized property shows one row per language the source has seen, each tagged with its language code.

Hovering a value reveals a copy button.

### Adding list values

**Add new value** on a list property opens a box where several values can be entered at once, separated by commas or new lines. They are merged with the existing ones, duplicates dropped.

## Save

**Save** stays disabled until you change something, and while the source is being purged. On success the panel closes.

## Changelog

The **Changelog** section lists changes newest first, labelled **Added**, **Updated** or **Removed**. Each row shows the property, the before and after values, when it happened, and who or what made the change — a data provider or a Studio user.

Only the most recent change is shown at first; **View all** expands the list and **Show less** collapses it again.

<Info>
Changes made by an integration appear here too, which makes the changelog the quickest way to see whether a value came from onboarding or from someone editing it in Studio.
</Info>
