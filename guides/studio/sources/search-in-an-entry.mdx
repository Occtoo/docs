---
title: "Search in an entry"
---

When data is onboarded in the source you have the possibility to serach inside an entry on a specific property

- Open the source that you would like to see the entry for
- Serach for the entry you would like to see the property for

<Info>
You search on the property name that is added in the source
</Info>
