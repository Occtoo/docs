---
title: "Import data"
---

A provider is a custom integration used to populate the data sources sources inside Occtoo.

In the provider, custom business logic can be added to meet the specific requirements. If you want to ingest data into a source - a data provider needs to be created and a provider ID has to be used in conjunction with a provider secret to write data.

Follow our quick start guides to quickly get started with onboarding data:

- [Get data into Occtoo](/get-started/get-data-into-occtoo)
