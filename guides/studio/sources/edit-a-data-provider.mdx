---
title: "Edit a data provider"
---

<Steps>
  <Step title="Open Data providers">

    Select the tab Data providers.

  </Step>
  <Step title="Open the provider menu">

    Select the menu at the right on the specific data provider that you would like to edit

    ![An image from the static](/images/guides/studio/sources/edit-data-provider1-e3c689bd6fd619cbf6632bc6c2128985.png)

  </Step>
  <Step title="Edit the provider details">

    <Info>
    You are able to edit the name of the data provider and the "Allowed sources" that you are able to onBoard data into, by adding them to allowed
    </Info>

    ![An image from the static](/images/guides/studio/sources/edit-data-provider2-7df7fdf3f77f932a5c76cf7525d4c2de.png)

  </Step>
</Steps>
