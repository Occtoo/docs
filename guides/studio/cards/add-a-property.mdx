---
title: "Add a property on an existing card"
---

<Steps>
  <Step title="Open the card">

    Select the card and open it.

  </Step>
  <Step title="Select Add Property">

    Select **Add Property**.

    ![An image from the static](/images/guides/studio/cards/how-to-add-property-1-4a6ae0a628d97988f65fe59817366255.png)

  </Step>
  <Step title="Add property details">

    Add the following information

    - **Name** – Choose the name for your card
    - **Identifier** - Identifier will be automatically filled using the name you chose in the previous step. You will have the possiblity to change it if needed.
    - **Data source** - Select the data source for the field
    - **Data source property Id** - Select the property id from the data source dropdown
    - **Description** – Add a description if needed
    - **Data type** - Select the data type for the field

    <Info>
    If you are adding a type="List", you need to select the delimiter that seperates the value in the source of this field (such as "|").
    </Info>

    ![An image from the static](/images/guides/studio/cards/how-to-add-property-2-98e498f7aa1b2a7f426a4e925badf863.png)

  </Step>
</Steps>

<Info>
If your card is in the **Draft** status you are able to do all the changes.
If your card is in the **Active** status your changes will appear as **Pending** until you activate them. You can review them under the tab **Changes**.
</Info>
