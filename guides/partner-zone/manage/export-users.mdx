---
title: "Export users to CSV"
---

- This chapter will explain how to: Export a list of users to a CSV file.

<Steps>
  <Step title="Open the user management page">

    Start by navigating to the user management page. This can be done by clicking the total number of users in the top menu.

    ![An image from the static](/images/guides/partner-zone/manage/partners-export3-b5016076857d152b7f40874216c592fb.png)

  </Step>

  <Step title="Click 'Export CSV'">

    ![An image from the static](/images/guides/partner-zone/manage/partners-export5-0191cd5cb570b7691d8c6b34394a85db.png)

    An export can be done from the 'All users' view by clicking 'Export CSV'

  </Step>

  <Step title="Export from a partner view">

    A list export can also be done from each Partner view

    An export can be done from the 'Partner user' view by clicking 'Export CSV'

    ![An image from the static](/images/guides/partner-zone/manage/partners-export6-98a3f11e9f5a4651fee92f04ec6d828d.png)

  </Step>
</Steps>
