## About Brink

Brink Commerce is a composable e-commerce platform that lets retailers build faster, adapt quicker, and spend less.

Read more at [brinkcommerce.com](https://www.brinkcommerce.com/).

## Introduction

This is a template project for building a formatter that sends data from an Occtoo destination to [Brink Commerce](https://www.brinkcommerce.com/). The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Formatter.Brink).
