## About Centra

Centra serves both wholesale and direct-to-consumer sales. It enables brands to handle all channels from one platform - both Wholesale B2B and Direct-to-Consumer B2C.

Read more at [https://centra.com](https://centra.com)

## Introduction

This is a template project for creating provider to onboard data from [Centra](https://centra.com). Available via [Github](https://github.com/Occtoo/Occtoo.Provider.Centra).

## How it works

The solution has functions working as shown below:

![Architectual Overview](/images/integrations/providers/CentraProvider-fe9cec1129f812c7007288ad9373fc91.png)

FillQueueFromCentra (HttpTrigger) - Called to start moving products from Centra API into the queue

ImportQueuedItemsToOcctoo (QueueTrigger) – Picks up the queue items and create a key value entity ([Dynamic Entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs)) and sends it to Occtoo onboarding

Check our documentation on [how to set up a Provider in Occtoo Studio](/get-started/get-data-into-occtoo#1a-clientsecret) to get your provider details.
