## Introduction

This is a template project for building a provider that onboards data from [Azure Queue Storage](https://learn.microsoft.com/en-us/azure/azure-functions/functions-bindings-storage-queue-trigger?pivots=programming-language-csharp). The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Provider.AzureQueueTrigger).

## How it works

The project contains two functions:

- An HTTP-triggered function that adds three messages to the queue. Call it from a browser when running locally.
- A queue-triggered function that runs whenever a message is added and converts each message into a [dynamic entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs). The entities are then imported into Occtoo using the [OnboardingServiceClient](https://github.com/Occtoo/Occtoo.Onboarding.Sdk).

To get the provider details required by the template, see [Add a data provider](/guides/studio/sources/add-a-data-provider) and [Client/secret](/get-started/get-data-into-occtoo#1a-clientsecret).

## Download and installation

Fetch the latest code from our [GitHub repository](https://github.com/Occtoo/Occtoo.Provider.AzureQueueTrigger), then build and deploy it to your Azure instance.
