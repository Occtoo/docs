## About Akeneo

Akeneo is the Product Experience company, helping organizations deliver enriched, engaging, consistent, and compelling product experiences across all owned and unowned channels, including ecommerce, mobile, print, social commerce, points of sale, and beyond.

Read more at [akeneo.com](https://www.akeneo.com).

## Introduction

This is a template project for building a provider that onboards products, categories, and media from [Akeneo PIM](https://www.akeneo.com). The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Provider.Akeneo).

<Note>
The provider is no longer distributed as an app on the Akeneo marketplace. Download the source code from GitHub and deploy it yourself, in the same way as the other boilerplate providers.
</Note>

## How it works

The solution has three function pairs working as shown below.

![Architectural overview of the Akeneo provider](/images/integrations/providers/AkeneoProvider.jpg)

Two HTTP-triggered functions act as entry points. `PrepareAkeneoConnection` registers a connection for a tenant, and `StartDataSynchronization` starts the synchronization. From there, the start orchestration fans out into sub-orchestrations for categories, products, and media, which page through the Akeneo API and push the results to the Occtoo onboarding API. The date of the last successful synchronization is recorded per source, so subsequent runs only transfer what has changed.

To get the provider details required by the template, see [Add a data provider](/guides/studio/sources/add-a-data-provider) and [Client/secret](/get-started/get-data-into-occtoo#1a-clientsecret).
