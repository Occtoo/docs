## About Shopify

Shopify supports the next generation of entrepreneurs, the world's biggest brands, and everyone in between.

Read more at [shopify.com](https://www.shopify.com/).

## Introduction

This is a template project for building a provider that onboards data from the [Shopify API](https://shopify.dev/docs/api). The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Provider.Shopify).
