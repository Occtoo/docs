## Introduction

This is a template project for building a provider that onboards data from an XML file.

## How it works

The program reads the file `books.xml` and converts each book element into a dynamic entity. The entities are then imported into Occtoo using the OnboardingServiceClient.

To get the provider details required by the template, see [Add a data provider](/guides/studio/sources/add-a-data-provider) and [Client/secret](/get-started/get-data-into-occtoo#1a-clientsecret).

## Download and installation

Request the latest code from [developer@occtoo.com](mailto:developer@occtoo.com), then build and deploy it to your Azure instance.
