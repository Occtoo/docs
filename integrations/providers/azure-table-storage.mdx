## Introduction

This is a template project for building a provider that onboards data from [Azure Table Storage](https://learn.microsoft.com/en-us/azure/storage/tables/table-storage-overview). The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Provider.AzureTable).

## How it works

The program reads from the `books` table in an Azure storage account and converts each book element into a [dynamic entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs). The entities are then imported into Occtoo using the [OnboardingServiceClient](https://github.com/Occtoo/Occtoo.Onboarding.Sdk).

To get the provider details required by the template, see [Add a data provider](/guides/studio/sources/add-a-data-provider) and [Client/secret](/get-started/get-data-into-occtoo#1a-clientsecret).

## Download and installation

Fetch the latest code from our [GitHub repository](https://github.com/Occtoo/Occtoo.Provider.AzureTable), then build and deploy it to your Azure instance.
