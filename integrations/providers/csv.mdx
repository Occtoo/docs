## Introduction

This is a template project for building a provider that onboards data from a CSV file. The code is available on [GitHub](https://github.com/Occtoo/Occtoo.Provider.CSV).

## How it works

The program reads the file `Product_Data_Sample.csv` and converts each row into a [dynamic entity](https://github.com/Occtoo/Occtoo.Onboarding.Sdk/blob/main/src/Occtoo.Onboarding.Sdk/Models/DynamicEntity.cs). The entities are then imported into Occtoo using the [OnboardingServiceClient](https://github.com/Occtoo/Occtoo.Onboarding.Sdk).

To get the provider details required by the template, see [Add a data provider](/guides/studio/sources/add-a-data-provider) and [Client/secret](/get-started/get-data-into-occtoo#1a-clientsecret).

## Download and installation

Fetch the latest code from our [GitHub repository](https://github.com/Occtoo/Occtoo.Provider.CSV), then build and deploy it to your Azure instance.
